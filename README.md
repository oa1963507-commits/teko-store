# TEKO STORE — متجر تخصيص الهوديز

الموقع: https://oa1963507-commits.github.io/teko-store/

## الوضع الحالي

- محرر الهودي بأربع زوايا، ورفع التصميمات الأصلية، والنصوص، وضبط مكان الطباعة والمقاسات.
- رفع ZIP الخاص لكل طلب إلى Supabase Storage، مع روابط تحميل موقعة لمدة 7 أيام وإرفاق الرابط في نص واتساب.
- حماية الرفع بـ Cloudflare Turnstile. عند تعذر الرفع يمكن تنزيل ZIP ومشاركته يدويًا.
- تم إعداد وظيفة وجدولة Supabase لحذف ملفات ZIP التي تتجاوز 7 أيام. راجع سجلات Cron وEdge Function عند متابعة التشغيل.
- حفظ مسودة التصميم محليًا في المتصفح (IndexedDB).

## المرحلة V24 قيد التفعيل

تم **تجهيز الكود فقط** لتسجيل الطلبات مركزيًا ولوحة مالك آمنة تشمل البحث وحالات الطلب وتنزيل ZIP.
هذه الميزة **ليست مفعلة بعد على Supabase**، ويظل وضع تسجيل الطلبات في قاعدة البيانات مقفولًا عبر:

- order-cloud-config.js: databaseOrdersEnabled = false
- owner-config.js: publicKey فارغ، فلا يمكن تسجيل دخول الإدارة بعد

الخطوات مرتبة في:

[إعداد قاعدة البيانات ولوحة المالك](supabase/SETUP_OWNER_AR.md)

يجب تطبيق SQL ونشر Edge Functions وإنشاء حساب مالك وتثبيت المفتاح العام ثم الاختبار قبل تفعيل تسجيل الطلبات.

## الأمان

- ملفات العميلين وبياناتهم لا تُرفع إلى GitHub ولا تُدرج في ملفات المشروع.
- التخزين الخاص محمي بـ Supabase signed URLs، بينما الوصول إلى الطلبات في لوحة المالك سيكون بعد تحقق Supabase Auth ومعرف المالك.
- لا تضع service_role أو sb_secret_ أو الأسرار الأخرى في JavaScript علني.
- واجهة لوحة المالك التجريبية داخل المتجر الحالي ما زالت محلية وغير آمنة للطلبات المركزية؛ لوحة owner.html الجديدة مستقلة ومغلقة حتى إكمال إعداد الحساب.
- أسعار العملاء في بيانات الطلب عروض تقديرية ولا تُعتبر مدفوعات مؤكدة.
