# TEKO STORE — Real Hoodie Color Photos

All files listed here belong directly in `assets/` (the olive color already uses the existing `hoodie-front.png`, `hoodie-back.png`, `hoodie-left.png` and `hoodie-right.png`).

New colors require **4 images each**, and names must match the following conventions:

- `hoodie-burgundy-{front,back,left,right}.webp`
- `hoodie-brown-{front,back,left,right}.webp`
- `hoodie-gray-{front,back,left,right}.webp`
- `hoodie-navy-{front,back,left,right}.webp`
- `hoodie-white-{front,back,left,right}.webp`
- `hoodie-black-{front,back,left,right}.webp`
- `hoodie-beige-{front,back,left,right}.webp`

These are **28 independent files**, not a collage. Color switching in the editor uses the uploaded photograph for the selected color and the selected angle, retaining overlay artwork in its original position.

If an image is missing during the transition, the application temporarily falls back to the older color simulation. Once all photos are uploaded and the site is refreshed, the simulation will not be used.

Existing files `teko-brand.png` and `size-chart.png` remain unchanged.
