TEKO STORE — تجربة أولية لمحرر الهودي

التشغيل:
1) فك ضغط مجلد المشروع.
2) افتح index.html في متصفح حديث. يُفضّل تشغيله باستضافة محلية لتوافق الميزات.
3) يمكن فتح الصفحة محليًا مباشرة؛ تم تضمين الصور الأصلية داخل ملف JavaScript لمنع مشكلة أمان Canvas التي كانت تمنع تغيير اللون.
4) لتشغيل سيرفر محلي إذا كان Python مثبتًا: python -m http.server 8000
5) افتح http://localhost:8000

المنجز في النسخة الأولية:
- الهوية البصرية TEKO STORE مستوحاة من الملفات المرفوعة.
- عرض زوايا الهودي الأربعة باستخدام صور العميل الأصلية بدون تعديل الملفات.
- إصلاح اختيار 8 ألوان ليعيد تلوين صورة الهودي فورًا، حتى عند فتح index.html مباشرة من الجهاز.
- اختيار 5 مقاسات وجدولها من صورة العميل.
- معرض تجريبي قابل للإضافة من لوحة تجريبية.
- رفع صورة المستخدم أو كتابة عبارة مع خط ولون.
- تحريك التصميم بالسحب وتغيير حجمه بالسحب أو بالسنتيمتر، بحد أقصى للطباعة 40 سم عرض × 45 سم ارتفاع.
- تحديد الجيب وبعض مناطق الخياطة بخطوط حمراء عند التداخل؛ مناطق تقديرية.
- تحميل معاينة المنتج، وحفظ طلب محلي مع فتح رسالة واتساب تحتوي البيانات.
- مشاركة الملفات عبر واجهة المشاركة الأصلية في الأجهزة التي تدعمها.
- تغيير السعر والخصم محليًا.

حدود النسخة التجريبية (مهمة):
- ليست متجر إنتاج أو نظام طلبات مركزيًا؛ لوحة المالك التجريبية لا تحتوي مصادقة آمنة.
- الطلبات والإعدادات محفوظة محليًا في المتصفح، وليست مرئية على أجهزة أخرى.
- إرسال الموكاب والملف تلقائيًا إلى رقم واتساب بعينه غير ممكن عبر wa.me؛ يحتاج استضافة الملفات/روابط أو إجراء مشاركة يختاره العميل.
- معايرة قياس الطباعة بالسنتيمتر وخطوط منع الخياطة/التطريز والجيب تقريبية إلى أن تتوافر خريطة طباعة ميدانية بأبعاد حقيقية.
- تغيير ألوان الصور محاكاة وليست تصويرًا واقعيًا معتمدًا لكل لون، ويجب مراجعة درجات المخزون.
- نموذج المعرض يحتوي تصميمات نصية أولية فقط؛ العميل لم يقدم المكتبة الفعلية بعد.
- التحقق من جودة ملفات DTF وإنتاجها غير متوافر حاليًا.

للنشر النهائي: Backend آمن مع مصادقة مالك + قاعدة بيانات الطلبات + تخزين صور/ملفات ورفع آمن + قواعد الصلاحيات وسياسة خصوصية + معايرة الطباعة + طريقة موثوقة لإرسال روابط ملفات الطلب.
