# TEKO STORE — GitHub Pages prototype

هذه نسخة تجريبية من محرر الهودي، معدة للعمل على استضافة HTTPS بدون ملف الصور المدمج الكبير.

## النشر لمرة واحدة

1. افتح https://github.com/new وأنشئ مستودعًا **Public** باسم `teko-store`، وفعّل خيار Add README إذا أردت.
2. ارفع **محتويات المجلد نفسه** إلى جذر المستودع (ليس المجلد الأب): `index.html` و `app.js` و `assets/` و `.nojekyll`.
3. من **Settings → Pages → Build and deployment** اختَر **Deploy from a branch**، والفرع `main`، والمجلد `/(root)`، واضغط Save.
4. سيظهر عنوان الموقع من قسم Pages؛ تعديلات الكود على فرع `main` تنشر تلقائيًا. قد يلزم انتظار النشر أو إعادة تحميل الصفحة لتجاوز التخزين المؤقت.

## ملاحظات أمان وتشغيل

- **هذه نسخة نموذجية فقط وليست متجرًا جاهزًا لاستلام طلبات فعلية**؛ لوحة المالك الحالية تعمل محليًا على جهاز الزائر وليست نظام صلاحيات آمنًا.
- ملفات الطلبات والتصميمات المرفوعة لا تُخزن على قاعدة بيانات مركزية؛ يتطلب التشغيل الحقيقي Backend وتخزين ملفات وصلاحيات آمنة.
- GitHub Pages يعرض ملفات المستودع العام للزوار؛ **لا تضع مفاتيح سرية أو بيانات عملاء** داخل الكود.
- موقع GitHub Pages يقدّم الملفات الثابتة فقط. أي حفظ آمن للطلبات وإرسال ملفات عبر واتساب يتطلب خدمة خلفية أو تكاملًا إضافيًا.
- هذا الإصدار يستخدم صور PNG في `assets/` مباشرة ويحتاج التشغيل من HTTPS (أو localhost) لعمل Canvas وإعادة التلوين. لا يُنصح بفتحه عبر `file://`.
